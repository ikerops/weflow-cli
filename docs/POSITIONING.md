# 这个项目靠什么活着（定位与护城河）

> 写于 2026-10-19，起因是微信 4.1.15 把「问 AI 总结文件和公众号文章」做进了客户端。
> 这个问题值得认真回答，因为答案决定了后面所有功能该不该做：**如果价值只是"用 AI 把微信里
> 已有的内容处理一遍"，那微信自己会做，而且做得更顺（右键就有）。**

## 一句话

**不是"更好用的微信"，是"能被带走、能被追问、能穿越时间的个人历史"。**

判据只有一个：**能不能回答微信回答不了的问题。** 答不了，就只是给微信套了一层 AI，别人没有理由换。

## 微信最近做了什么（2026-09-15，4.1.15 Win/Mac）

官方只承认两条，实测多出四条（[IT之家](https://www.ithome.com/1/003/287.htm)）：

| 更新 | 影响 |
| --- | --- |
| **文件和公众号文章支持「问 AI」** | ⚠️ 直接撞在我们"AI 读内容"的一半上 |
| 双人语音/视频通话可邀请他人加入 | 通话功能，与数据无关 |
| 群通话可邀请不在群里的人 | 同上 |
| 侧边栏新增「发现」 | UI 收敛 |
| 群免打扰可设「仍通知」（@我/@所有人/群公告 + 4 个成员） | 消息管理 |
| 聊天旁三栏浏览区，可独立窗口/吸附 | 阅读体验 |

`.53` / `.56` 这类构建**没有公开更新日志**（官网日志仍停在 4.1.15 / 09-15，GitHub 归档只到 `.53`）。
从安装目录看，变动集中在 `RadiumWMPF.bin`（412 MB，小程序/浏览器内核）、`WeChatOcr.bin`、
`XFilesOfficeReader`、`WePlayer` 这些组件——热修通常动内核，不动产品形态。

**要盯的方向**：微信正在把 AI 往"单文件/单文章"上做。它越做，越说明"跨内容、跨时间"那层是空白。

## 五条护城河（按"腾讯为什么不会做"排序）

| 护城河 | 微信不做/做不到的原因 | 我们的证据（可复验） |
| --- | --- | --- |
| **数据出口** | 微信从不提供导出聊天/朋友圈/收藏；"迁移"只到手机。4.1.15 六条更新里**没有一条**开放数据 | `export` 输出 HTML/md/json/xlsx + 图片与文件本体；issue #11 已修 |
| **纵向时间** | 微信的搜索只服务"找那条消息"，不做"这个人三个月的变化""这件事我答应过几次" | 欠话台账、关系温度（`bonds`）、承诺追踪（`todos`）、日报归档（372 天） |
| **跨库联合** | 微信是产品不是平台：不会读你的 Obsidian、代码仓库、订阅源 | 语义索引 ~16k 条（聊天 5.2k + 文章 10.7k），实测 recall@10 **0.95**；原样定位（FTS5）；Vault 概念页 |
| **本地/隐私** | 微信的 AI 必走它自己的云；承诺"不出本机"等于砍掉它的商业模型 | 支持 Ollama/LM Studio；`judgeProvider=chat` 必须尊重 `aiEngine=local`（D-124） |
| **可溯源** | 微信的「问 AI」给你一段总结，**点不回原句** | 每条命中带 `id`/`sourceFile`/原文链接，能回到那两个字节 |

## 会被立刻吃掉的功能（别把力气花在这里）

- 单篇文章/单个文件摘要 —— 4.1.15 已做；
- 会话内关键词搜索 —— 微信自带（虽然不全）；
- 通用"和 AI 聊微信记录" —— 门槛极低，人人能做；
- 任何"把微信 UI 做得更顺手"的尝试。

## 四个能验的问题（产品自测题）

只要这四类问题答得比微信好，这个项目就成立：

1. **"我三个月前答应过谁什么，兑现了吗"** —— 跨时间 + 承诺追踪。
2. **"我和谁的关系在变淡，还救得回来吗"** —— 纵向聚合；微信只给当下。
3. **"这个号今年发了几篇，观点怎么变的"** —— 跨文章统计；微信只给单篇。
4. **"那句话他原样写过吗，哪天"** —— 原样定位；微信搜不到三个月前的群聊。

## 因此，产品的三个"不做"

1. **不追微信的新功能**（右键问 AI、发现页、三栏阅读）——那是它的产品节奏，追不上也没意义。
2. **不做纯 UI 替代品** —— 用户没有理由因为"更好看的聊天窗口"而迁移。
3. **不把 AI 摘要当成卖点** —— 摘要人人能做；**能溯源、能跨时间、能带走**才是。

## 这个判断会过期的情形

如果哪天微信真的开放了"导出全部聊天记录"或"本地数据 API"，第一条护城河会塌一半——
到那时要立刻重估：**是不是该转向"分析层"（纵向/跨库/证据链），而不是"读取层"**。
这件事目前没有任何迹象，但要盯住更新日志里出现 `export` / `开放平台` / `本地数据库` 这类字眼。
